# Coffee Shop Sales Dashboard

## Overview
This project analyzes coffee shop sales data and presents key metrics in an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- Pivot Charts
- Slicers

## Dashboard Preview
![Image](Coffee%20Shop%20dashboard.jpg)

## Key Metrics
- Total Revenue: $112,245.58
- Total Quantity Sold: 3,547
- Total Transactions: 3,547

## Key Insights
- Latte generated the highest revenue.
- March and October recorded the strongest sales.
- Tuesday had the highest transaction count.
